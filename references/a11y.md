# Accessibility & Keyboard Contract

A11y is code quality (tesd-stack rule), not a garnish. Every component ships this contract with its markup.

## Global contract

- **Skip link** — first focusable element: "Skip to content" → `#main`; visible only on focus.
- **Focus visibility** — the unified ring (`--focus-ring` + accent border) on every bordered control; 2px outline fallback on borderless elements (links, nav). The ring never animates.
- **Contrast** — text pairs pass AA: `--ink`/`--ink-2` on paper, `--muted` for secondary ≥ 14px, `--accent-text` (theme-paired) for accent text, never raw `--accent` for small text on paper.
- **Reduced motion & transparency** — see motion.md; motion collapses to cross-fades, frosted surfaces go solid.
- **Icons** — decorative → `aria-hidden`; solo icons live on labeled buttons (icons.md).
- **Language** — English copy; headings roman, never italic.
- **Landmarks** — `header/nav/main/footer` + section `aria-label`s; one `h1`.

## Component contracts

| Component | Semantics | Keyboard | Behavior |
|---|---|---|---|
| **Tabs** | `role="tablist"` / `tab` / `tabpanel`, `aria-selected`, `aria-controls` | ← → move selection, Home/End jump, **roving tabindex** (active `0`, others `-1`) | panels toggle `hidden`; selection follows focus |
| **Modal** | `role="dialog"` + `aria-modal` + `aria-labelledby` on scrim | Tab/Shift+Tab **trapped** inside; Escape closes | focus in ~120ms after open → first control; focus returns to trigger; body scroll locked; scrim click + explicit close buttons |
| **Menu sheet** | trigger `aria-expanded` + `aria-controls` | Tab trapped inside; Escape closes | focus moves to first link on open; returns to burger on close; link click closes; scroll locked |
| **Segmented** | `role="group"` + `aria-label`; options `aria-pressed` | native buttons (all tabbable) | pressed state mirrors `.is-active` |
| **Switch** | native checkbox + `role="switch"` inside `<label>` | Space toggles (native) | companion `.switch` visual; state label reflects on/off |
| **Checkbox/Radio** | native inputs (visually hidden) + companion shapes | Space / arrows (native radio group via `name`) | focus ring lands on companion via `:focus-visible + companion` |
| **Forms** | `<label for>`; `aria-invalid` on error; msg `aria-live="polite"`; help/messages via `aria-describedby` | native | validation live on `input`; submit focuses first invalid field |
| **Tooltip** | `role="tooltip"`, host `aria-describedby` | Escaped by focus/blur (`:focus-within`) | hover/focus only; wraps (max-width 200px) |
| **Toasts** | container `aria-live="polite"` | — | auto-dismiss 2.6s; ≤3 visible; message text only (no critical info sole-sourced) |
| **Pagination** | `nav[aria-label]`; current = `aria-current="page"` | native buttons | disabled prev/next reflect bounds; wraps on narrow screens |
| **Table** | real `<th scope="col">` | — | horizontal scroll inside `.table-scroll` only; two-line cells via `.cell-title/.cell-sub` |
| **Drawer** | `role="dialog"` + `aria-modal` + `aria-labelledby` | Tab trapped; Escape closes | focus in/out like modal; bottom-sheet geometry on mobile |
| **Dropdown** | trigger `aria-haspopup` + `aria-expanded`; `menu` / `menuitem` / `separator` | ↑↓ cycle items; Escape returns to trigger; Enter native | click-outside closes; danger item last |
| **Palette** | input `role="combobox"` + `aria-activedescendant`; listbox/options `aria-selected` (roving) | ↑↓ move, ↵ run, Esc closes, ⌘K toggles | filter-as-type; focus returns to trigger; overlays are exclusive |
| **Combobox** | input `role="combobox"` + `aria-expanded` + `aria-controls` + `aria-activedescendant`; listbox `role="listbox"`; options `role="option"` + `aria-selected` | ↑↓ move roving focus, ↵ select, Esc closes, type filters | filter-as-type; click-outside closes; inline pure-CSS positioning; scroll containment |
| **Datepicker** | input `aria-haspopup="dialog"` + `aria-expanded` + `aria-controls`; dialog `role="dialog"`; grid `role="grid"`; day cells `role="gridcell"` + `aria-selected` | ↑↓←→ cycle days, ↵ select, Esc closes; native `showPicker()` on touch | dual-mode: native OS wheel/dialog on mobile, keyboard accessible calendar on desktop |
| **Sortable table** | `th[aria-sort]` + `tabindex="0"` | Enter/Space sorts | instant reorder (data change, no animation); master checkbox uses `indeterminate` |
| **Burger** | `aria-expanded` + `aria-label` (Open/Close menu) | Enter/Space (native) | morphs to X; stays above the sheet |

## The trap helper

One implementation, used by modal and menu:

```js
function trapTab(container, e) {
  var f = container.querySelectorAll('a[href], button:not([disabled]), input, select, textarea, [tabindex]:not([tabindex="-1"])');
  if (!f.length) return;
  var first = f[0], last = f[f.length - 1];
  if (e.shiftKey && document.activeElement === first) { e.preventDefault(); last.focus(); }
  else if (!e.shiftKey && document.activeElement === last) { e.preventDefault(); first.focus(); }
}
// wired: overlay.addEventListener('keydown', function (e) { if (e.key === 'Tab') trapTab(overlay, e); });
```

Focus-in/out pattern for overlays: on open, `setTimeout(focus first control, 120)` (post-animation); on close, `trigger.focus()`.

## Verification recipe (headless)

Dispatch synthetic `KeyboardEvent`s and assert state — see the simulation probe used in the preview audit: tabs (ArrowRight moves `aria-selected` + focus + roving tabindex), modal (Tab at boundary wraps, Escape closes + focus returns to the **remembered** trigger — note: synthetic `.click()` does not move focus, so focus the trigger explicitly in tests), menu (focus in on open, returns to burger), segmented `aria-pressed`. Manual fallback: a full Tab-walk through the page must never lose the ring or trap outside overlays.

In Svelte (svelte.md seeds), the same contracts live inside the components — Modal encapsulates trap/Esc/focus-return, so pages cannot get it wrong.
