Accordion · disclosure — click to expand

What are design tokens?

Named entities that store visual attributes (colors, fonts, radii, spacing). When a token changes, every UI element referencing that token updates simultaneously.

Why is GSAP the single motion engine?

GSAP allows choreography, reverse/seek timelines for decks, stall-guard watchdog protection, and pausing off-screen loops without CSS keyframe delay hacks.

How does dark mode inversion work?

A single [data-theme="dark"] attribute inverts the semantic tokens. Components never branch for themes — alpha fills use color-mix() against the ink token.

Overlays

modal · drawer → bottom sheet · dropdown · ⌘K palette

Every overlay follows both contracts — the animation contract (staggered entrances, fast exits) and the a11y contract (focus trapped, Escape closes, focus returns to its trigger). The palette also opens with ⌘K / Ctrl+K anywhere.
